v3.0.1
Save compatible. Can be added to existing saves.

v3.0.0
Not save compatible with previous versions of the mod. Can be added to existing saves.

- Updated for Starsector 0.98.5a.
- Completely redesigned UI.
- Added a setting for the cost of removing a gacha hullmod.
- Every ship is now guaranteed a 5 star within 30 rolls.
- Rolls no longer give effects the ship can't use (fighter effects with no fighter bays, missile effects with no missile mounts, shield effects with no shield).
- Buffed Mirror Skin (1% to 5%) and Parting Gift (30% to 50%).
- Fixed Mirror Skin reflecting 10x too much beam damage, and Null Frame wasting its cooldown on beams.
- Reduced the SPD IV's effect on turn acceleration.
- Removing a gacha hullmod costs twice as much in Survival Mode. Added a setting to turn this off.
- Added a Reroll the IVs hullmod.
- In a sector with no Galatia Academy, such as some Nexerelin random sectors, the gacha starts at another market.
- jars directory now has the zipped source code


v2.0.1
Save compatible. Can be added to existing saves.

v2.0.0
Probably not save compatible with previous versions of the mod. Can be added to existing saves.

- Reworked rolls with 5 custom power tiers, that should make things more "balanced" and interesting.
- Every roll has a 20% chance to come with a second effect.
- 29 new rollable effects, including new super-interesting super-cool 20 gacha-exclusive ones (Null Frame, Mirror Skin, Mine Fabricator, Opening Statement, Hemovore Array, Heads or Tails, etc.).
- The hullmod tooltip now shows each rolled effect's name above its effect.
- Closed a free-reroll exploit: undoing your refit changes after a roll no longer lets you roll again.
- Rolling on ship modules is blocked now. It never did anything.
- Fixed the SP ATK IV modifying ballistic damage instead of energy damage.
- Fixed typos in text.
- Updated to 0.98a-RC8.
